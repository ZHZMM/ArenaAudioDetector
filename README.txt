ArenaAudioDetector v1.0 —— 便携版（Portable）
================================================

【软件简介】
开源、免费、完全本地运行的音频频谱识别工具。实时监听本机扬声器声音，当出现
《暗区突围：无限》的「大金 / 小紫」掉落、拾取音效时，在置顶浮窗提示物品与组别。
不读取游戏内存、不注入、不联网、不上传任何数据。

【如何使用】
1. 双击本目录内的  ArenaAudioDetector.exe  即可运行（无需安装）。
2. 首次启动请阅读并勾选同意用户协议（EULA）。
3. 在主页选择监听设备（带 ★ 的默认环回设备即可），点击「开始监听」。
4. 游戏内出现大金音效时，屏幕右上角浮窗会显示识别结果。

【快捷键】
  Ctrl + Alt + S    开始 / 停止监听
  Ctrl + Alt + G    开启 / 关闭抗环境音（仅适配地图：农场、山谷）
  （均可在「设置」中自定义）
